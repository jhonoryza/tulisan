# PostgreSQL Full-Text Search, Typo search (fuzzy search) and Autocomplete

## Full Text Search (FTS)

1. Builtin menggunakan tsvector
2. Extension [pg_textsearch](https://github.com/timescale/pg_textsearch)
3. Extension [pg_search](https://www.paradedb.com/blog/introducing-search)

## Typo search (fuzzy search) and Autocomplete

1. Native Extension [pg_trgm](https://www.postgresql.org/docs/current/pgtrgm.html)
